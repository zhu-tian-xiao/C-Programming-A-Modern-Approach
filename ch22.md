# Input/Output
## Streams
the term stream means any source of input or any destination for output.
### File Pointers
Accessing a stream in a C program is done through a file pointer, which has type `FILE *`
```c
FILE *fp1, *fp2;
```
### Standard Streams and Redirection
<stdio.h> provides three standard streams (Table 22.1). These streams are ready to use—we don’t declare them, and we don’t open or close them.
```c
demo <in.dat >out.dat
```

Text files have two characteristics that binary files don’t possess:
- Text files are divided into lines.
- Text files may contain a special “end-of-file” marker.
## File Operations
### Opening a File
```c
FILE *fopen(const char * restrict filename,
const char * restrict mode);
```
