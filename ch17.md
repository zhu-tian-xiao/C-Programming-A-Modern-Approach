## Dynamically Allocated Strings
### Using Dynamic Storage Allocation in String Functions
```c
char* concat(const char* s1, const char* s2) {
	char* result;
	result = malloc(strlen(str1) + strlen(str2) + 1);
	if (result == NULL) {
		printf("Error: malloc failed in concat\n");
		exit(EXIT_FAILURE);
	}
	strcpy(result, s1);
	strcat(result, s2);
	return result;
}
```
